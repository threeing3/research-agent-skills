# VideoQA and Long-Video Lenses

Map each candidate across:

- temporal span and event density;
- evidence localization and retrieval;
- multi-event, causal, counterfactual, and compositional reasoning;
- question-conditioned perception;
- audio, speech, subtitles, OCR, and visual evidence;
- memory compression, forgetting, and evidence retention;
- distractors, hallucination, uncertainty, and abstention;
- annotation leakage, answer priors, benchmark contamination, and judge reliability;
- streaming versus offline access;
- accuracy, latency, token use, memory, and compute trade-offs.

Cross-domain sources with useful structural analogies include information retrieval, database query planning, streaming algorithms, control theory, cognitive memory, causal inference, program analysis, active perception, information theory, and sequential decision-making.

For every transfer, specify entities, relations, conserved mechanism, broken assumptions, and a prediction that differs from standard VideoQA baselines.
