# VideoQA Experiments

For VideoQA and long-video understanding, consider:

- performance stratified by duration, event density, question and reasoning
  type;
- evidence-frame or temporal localization quality;
- context, frame, token, and memory budgets;
- distractor resistance, answer priors, leakage, and judge reliability;
- memory retention, retrieval, compression, and forgetting ablations;
- cross-dataset transfer and out-of-distribution behavior;
- latency, throughput, peak GPU memory, and cost;
- audio, subtitle, OCR, and visual modality contribution;
- qualitative failures with a defined sampling and annotation protocol.

Bind each formal analysis to a hypothesis or claim. Keep dataset-specific
answer normalization and evaluation versions in every run manifest.
